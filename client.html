Every frame you see is hallucinated by a neural network — there is no game engine. This is a Genie-style world model (video tokenizer + unsupervised latent actions + MaskGIT dynamics), trained from scratch on self-generated CoinRun data. Pick a scene, then steer its dream.

Arrow keys or click. Each press adds a latent action and the model re-dreams the trajectory. The 7 actions were learned unsupervised — part of the fun is discovering what each one does.
tokenizer 100M dynamics ~250M trained from scratch data self-generated (CC0) recon PSNR ~18–19
Built overnight: procgen→dataset engine, a from-scratch 100M ST-ViViT tokenizer (recon loss 0.0005), then a ~250M unsupervised-latent-action MaskGIT dynamics model (40,000 steps on 8×H100), all on Modal — then served here so you can play inside its dream. The model runs un-distilled (~1 fps, 16 MaskGIT steps/frame), so each dream takes a moment to form.
